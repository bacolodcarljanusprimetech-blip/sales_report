PROJECT NAME:
Sales Rep Daily Picture Report PDF Creator

PROJECT TYPE:
Lightweight web application for creating professional PDF reports from sales representative photographs.

==================================================
1. PROJECT OBJECTIVE
==================================================

Build a lightweight web application that allows sales representatives or office staff to:

1. Upload multiple report pictures.
2. Preview the uploaded pictures.
3. Reorder pictures using drag and drop.
4. Rotate pictures.
5. Delete pictures.
6. Automatically handle pictures with different/random dimensions.
7. Automatically fit every picture correctly onto an A4 PDF page.
8. Preserve the original image aspect ratio.
9. Prevent image stretching or distortion.
10. Add optional report information.
11. Generate a professional PDF.
12. Preview the PDF/report before downloading.
13. Download the generated PDF.
14. Eventually support PDF security/password protection if technically supported by the approved stack.
15. Keep the application lightweight and processor-efficient.

IMPORTANT:
The timestamps are ALREADY EMBEDDED INSIDE THE IMAGES.

The sales representatives have already edited their photographs before submitting them, and the timestamp is visible as part of the actual image.

DO NOT implement OCR.
DO NOT attempt to extract timestamps from EXIF metadata.
DO NOT attempt to generate timestamps.
DO NOT modify or recreate the timestamp.

The timestamp contained in the image must remain exactly as it appears in the submitted image.

14. PDF FIT-TO-PAGE ALGORITHM
==================================================

Implement a reliable fit-to-page algorithm.

For every image:

1. Determine image width and height.
2. Determine its aspect ratio.
3. Determine available PDF content width and height.
4. Calculate the maximum proportional scale.
5. Scale width and height using the SAME scale factor.
6. Center the image on the page.
7. Keep consistent margins.
8. Never allow the image to exceed the page.
9. Never stretch the image.

Conceptually:

scale = minimum(
    availableWidth / imageWidth,
    availableHeight / imageHeight
)

finalWidth = imageWidth * scale

finalHeight = imageHeight * scale

Then center:

x = (pageWidth - finalWidth) / 2

y = (pageHeight - finalHeight) / 2

Adjust this algorithm if report headers/footers are present.
